## Project Vision and Philosophy
The vision behind the Personal AI Chatbot Widget is to provide a plug-and-play, enterprise-grade chatbot that any web developer can embed in under 5 minutes:
- **Security-First**: Built with guardrails preventing prompt extraction, jailbreaks, and sensitive key leakage.
- **Cost-Efficient**: Operates smoothly on Google's free-tier Gemini models with local vector caching.
- **Glassmorphic UI**: High-end dark aesthetic designed to match modern SaaS design systems.
